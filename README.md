## ✨ Features

- **🎯 30 Interactive MCQs:**
  - **CO-01:** Fundamentals of Distributed Computing & Message Passing (10 Questions)
  - **CO-02:** Remote Procedure Calls - RPC Design & Architecture (10 Questions)
  - **CO-03:** Distributed Shared Memory (DSM) & Clock Synchronization (10 Questions)
- **⚡ Instant Feedback & Score Tracking:** Immediate correctness checking, visual cues, Bloom's taxonomy tags (`BL1`, `BL2`, `BL3`), and live score counter.
- **💡 Dual Explanations:**
  - **Technical Explanation:** Rigorous exam-ready definitions and concepts.
  - **Hinglish Explanation:** Intuitive, relatable analogies for crystal-clear conceptual clarity.
- **📊 Descriptive Question Bank with Visual SVG Diagrams:**
  - **Q1:** Distributed Computing System Architecture vs Centralized Systems
  - **Q2:** Blocking vs Non-Blocking Message Passing Buffering & Semantics
  - **Q3:** Detailed 10-Step RPC Architecture & Sequence Flow
  - **Q4:** Distributed Shared Memory (DSM) Architecture (Page-based vs Object-based with side-by-side SVG comparisons)
  - **Q5:** Core DSM Design Challenges (Granularity, False Sharing, Consistency, Thrashing)
- **📱 Fully Responsive UI:** Built with Tailwind CSS and FontAwesome, looks clean on both mobile phones and desktop displays.

## 🛠️ Deploying to Vercel

This repository is **100% Vercel Ready** with a pre-configured `vercel.json` and standard `index.html` entry point.

### Option 1: One-Click Deploy Button
Click the button below to fork and deploy instantly on your Vercel account:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fhimesh112005%2FDistributed-Systems-mid-sem)

### Option 2: Import from GitHub
1. Sign in to [Vercel](https://vercel.com).
2. Click **Add New...** > **Project**.
3. Import `himesh112005/Distributed-Systems-mid-sem`.
4. Leave default settings (Framework: *Other* / *Static Site*).
5. Click **Deploy**!

### Option 3: Deploy with Vercel CLI
```bash
# Install Vercel CLI globally
npm install -g vercel

# Deploy directly from terminal
vercel
```

## 💻 Local Development

No heavy build steps or bundlers required. You can preview the application locally:

### Option A: Direct Open
Simply double-click `index.html` in your file explorer to open it in any modern browser.

### Option B: Local Server
```bash
# Using npx serve
npx serve .

# Or using Python's built-in server
python -m http.server 3000
```
Then visit `http://localhost:3000`.
